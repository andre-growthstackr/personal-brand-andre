# André Lundqvist – Personal Brand

Personlig portfolio och webbplats för **André Lundqvist** – Entreprenör, Growth Marketer & AI-entusiast, grundare av [GrowthStackr.io](https://www.growthstackr.io).

## Innehåll
- **Om mig**: Bakgrund och vision kring AI, automation och skalbar tillväxt.
- **Tjänster**: AI-implementering, Paid Growth & Funnels, Konverteringsoptimering (CRO) samt Data & Analys.
- **Projekt**: Utvalda kundcase och projekt.
- **Kontakt & Mötesbokning**: Länk till konsultation och kontaktuppgifter.
- **Interaktivitet**: Dark Mode / Ljust läge toggle.

## Teknikstack
- **HTML5** med semantisk struktur och SEO-optimering
- **Modern CSS3** med flexbox, CSS grid och färgvariabler för ljust/mörkt läge
- **Ren JavaScript** för responsiva funktioner
- Inga externa tunga ramverk krävs – snabb laddtid och optimal prestanda!

## Kör lokalt
Öppna bara `index.html` direkt i valfri webbläsare, eller använd en lokal server (t.ex. Live Server i VS Code / Antigravity).
